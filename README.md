# Rakamin-x-Kimia-Farma

## Latar Belakang
Proyek ini merupakan evaluasi terhadap kinerja bisnis operasional Kimia Farma selama periode 2020 hingga 2023. Analisis ini dibutuhkan untuk memahami tren pendapatan (nett sales) dan profitabilitas, serta mengevaluasi kualitas layanan cabang di berbagai wilayah untuk mendukung pengambilan keputusan yang berbasis data (data-driven decision making).

## Langkah Pengerjaan
1. Importing Dataset to BigQuery
2. Membuat Tabel Analisa dengan BigQuery Syntax
3. Membuat Dashboard  Performance Analytics (Google Data Studio)
